# C++ 学习工程

练习用的 C++ 工程集合（VS2022）。每个工程一个文件夹，互不依赖。

## 目录

| 目录 | 内容 |
| --- | --- |
| `封装链表-单文件/` | 单文件版链表：构造、析构、深拷贝、赋值重载、插入、删除都写在一个 .cpp 里 |
| `封装链表-分文件/` | 同一份逻辑拆成 `LinkedList.h`（声明）+ `LinkedList.cpp`（实现）+ `main.cpp`（测试） |
| `二叉树l26-11-23/` | 二叉树练习：建树、前中后序与层序遍历 |

## 打开方式

用 VS2022 打开对应目录里的 `.sln`：

- `封装链表-单文件/封装链表.sln`
- `封装链表-分文件/分文件.sln`
- `二叉树l26-11-23/二叉树l26-11-23.sln`

源码统一为 UTF-8 BOM，VS 里中文注释不会乱码。
